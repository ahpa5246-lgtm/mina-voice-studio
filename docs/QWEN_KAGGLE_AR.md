# Qwen3 VoiceDesign + Kaggle: تدريب/تقييم البداية

## ما نملكه الآن

- مسار عملي لابتكار أصوات من وصف مكتوب باستعمال النموذج الأصلي **Qwen3-TTS 1.7B VoiceDesign**.
- تخزين التسجيل المصمم ونصه ثم تمريره إلى **Qwen3 Base 1.7B** لاستنساخ الشخصية بين الجمل.
- التحكم بأسلوب الأداء عبر **Qwen3 CustomVoice** وأصواته الجاهزة فقط؛ لا ندّعي أن نموذج Base يستجيب لتعليمة السخرية أو البكاء.
- قياس ثبات الأصوات باستخدام بصمات متحدث Resemblyzer ومقارنة `within` و`between`، مع تنبيه أنها مؤشرات تقريبية.

## تشغيل التجربة على Kaggle مجانًا

1. افتحي https://www.kaggle.com/code ثم **New Notebook** وسجلي الدخول.
2. من **File → Import Notebook** استوردي الملف `kaggle/cartoon_voices_qwen3.ipynb` من مستودع Mina على GitHub (يمكن تنزيل الملف الخام أولًا).
3. من إعدادات الدفتر اختاري **Accelerator → GPU**، وفعّلي الإنترنت إذا سمح حسابك بإتاحة تنزيل أوزان Qwen العامة.
4. شغّلي الخلايا بالترتيب. ستثبت `qwen-tts` و`soundfile` و`resemblyzer` في بيئة Kaggle، ثم تنزل أوزان نماذج VoiceDesign وBase وCustomVoice.
5. بعد النجاح، اذهبي إلى **Output** ونزلي `mina-cartoon-voices.zip` الذي يتضمن تسجيلات WAV مرجعية لشخصيتين، ثلاث جمل لكل منهما، اختبارات أصوات جاهزة بانفعالات مختلفة، و`metrics.json`.
6. استمعي للتسجيلات أولًا؛ قارني إن كان صوت Shoko يبقى كما هو في جميع الجمل، وهل يمكن تمييز Robot عنه، وهل أداء السخرية/البكاء واضح فعلًا.

**مهم:** لم نشغّل دفتر Kaggle من حسابك ولم نتدرب على GPU حتى الآن. هو دفتر *استدلال وتقييم* وليس Fine-tuning. تخصيص النموذج بالتدريب يحتاج بيانات مرخصة ووقتًا وVRAM وبيئة إضافية. لا توجد أرقام واقعية للجودة أو VRAM قبل التنفيذ. موارد Kaggle مجانية لكن بحصص محدودة، وقد تُغلق الجلسة أو لا يتاح GPU. نموذج Qwen الرسمي لا يدعم العربية.

## قياس صوت حلقة منتجة في Mina

إذا حملتِ ZIP لحلقة من موقع Mina على جهازك:

```powershell
python -m pip install resemblyzer
python scripts/voice_consistency.py path\to\episode.zip --output report.json
```

يحسب `within_character_mean_cosine` و`between_character_mean_cosine` والفارق بينهما، مع حدود تفسير واضحة. لا تضعي قيمة ثابتة للنجاح قبل تجربة بيانات موسومة واختبارات استماع مستقلة.

**حقوق المصدر:** https://github.com/QwenLM/Qwen3-TTS (Apache 2.0). الأوزان وصلاحية الاستعمال وفق بطاقات النماذج الرسمية.

## تقرير ثبات الشخصية من داخل واجهة Mina

بعد أن تنتهي الحلقة من التوليد، يظهر زر **قياس ثبات أصوات الشخصيات**. لتشغيله ثبتي `resemblyzer` في بيئة Python التي تشغّل **خادم Mina** (وليس بيئة Qwen):

```powershell
python -m pip install resemblyzer
```

يعمل نموذج GE2E على ملفات الجمل الصوتية التي أنتجها المحرك فعليًا؛ ويحسب متوسط التشابه بين جمل الشخصية الواحدة وبين الشخصيات المختلفة. يحتاج عدة جمل واضحة لكل شخصية، ولا يفرض نتيجة نجاح افتراضية. لا يمكن الاستدلال من رقم مرتفع وحده على جودة التمثيل أو استقرار النطق بالعربية؛ لا بد من الاختبار السمعي.
