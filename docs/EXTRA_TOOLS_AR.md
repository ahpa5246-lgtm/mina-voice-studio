# أدوات Mina Voice Studio الجديدة — طريقة التشغيل الفعلية

## مباشرة، بدون تنزيل نماذج كبيرة

- **تنظيف WAV:** تشغيل فلتر High-pass وضبط Peak ومستوى ضوضاء اختياري — معالجة رقمية حقيقية، وليست نموذج AI لإزالة الضوضاء.
- **تحليل WAV:** قياس مستوى RMS والذروة والصمت والتشوه؛ لا يعد معيارًا طبيعيًا لجودة اللهجة.
- **مكتبة الأصوات:** تخزين 24 عينة صوتية مرجعية بحد 25MB لكل عينة في مجلد \`data/_voices\`. لا تحذفها وظيفة تنظيف التسجيلات المؤقتة. إذا أردتِ إزالة تسجيل، استخدمي زر الحذف.
- **التسجيل من الميكروفون:** تسجيل مقطع WAV لمدة خمس ثوانٍ في المتصفح، ثم تحويله باستخدام نموذج Applio مُثبت. هذه ليست ميزة تغيير صوت لحظي.
- **الدبلجة اليدوية:** ضعي النص المترجم من عندك في صفحة الدبلجة ثم اختاري صوتًا محفوظًا؛ سيُنشأ التعليق الصوتي باستخدام Chatterbox. لا توجد ترجمة تلقائية أو مزامنة شفة.

## التعرّف على الكلام بالعربية — Faster Whisper

في مجلد المشروع على PowerShell:

\`\`\`powershell
py -3.11 -m venv .venv-whisper
.\.venv-whisper\Scripts\python.exe -m pip install faster-whisper
$env:WHISPER_PYTHON = (Resolve-Path ".venv-whisper\Scripts\python.exe").Path
\`\`\`

يحتاج تنزيل أوزان نموذج Whisper المختار في أول تشغيل. أعيدي تشغيل الواجهة من نافذة PowerShell ذاتها؛ صفحة حالة الأدوات ستشير إلى ضبط مسار المحرك فقط، وليس ضمان نجاح تجربة فعلية.

## TTS-WebUI عبر API محلي

شغّلي TTS-WebUI مع إضافة OpenAI-compatible speech API محليًا، ثم في نافذة تشغيل Mina Voice Studio:

\`\`\`powershell
$env:TTS_WEBUI_URL = "http://127.0.0.1:7778"
\`\`\`

اذهبي إلى صفحة **المحركات الإضافية**. حددي \`model\` و\`voice\` المطابقين للإضافة المُثبتة؛ قد تختلف الأسماء والتوافق حسب الإضافة. الرابط الذي يظهر «مهيأ» هو ضبط عنوان URL فقط، لا دليل نجاح الصوت.

## GPT-SoVITS عبر API محلي

شغّلي \`api_v2.py\` وفق تعليمات GPT-SoVITS على منفذ 9880، ثم:

\`\`\`powershell
$env:GPT_SOVITS_URL = "http://127.0.0.1:9880"
\`\`\`

يستخدم الموصل \`/tts\` مع تسجيل مرجعي محفوظ في مكتبة Mina ومع نص التسجيل المرجعي. دعم هذا الموصل محصور في لغات النماذج المؤهلة التي تدعمها إعداداته (إنجليزي/صيني/ياباني/كوري في النموذج الحالي). العربية عبر Chatterbox. يجب أن ترى خدمة GPT-SoVITS ملف المرجع الموجود في نظام الملفات **نفسه**.

## التدريب وتغيير الصوت المباشر

- أداة \`scripts/dataset_audit.py\` تفحص تسجيلات التدريب المصحوبة بنصوص وبيانات إذن؛ وهي لا تدرب النموذج بذاتها.
- يمكن تشغيل خطوات التدريب الفعلية من تبويب «التدريب والبث الحي» بشرط ضبط Applio وبيانات تدريب مُرخّصة، لكن نجاح تدريب GPU الحقيقي لم يُتحقق منه هنا.
- واجهة تغيير الصوت **لحظيًا** غير متوفرة بعد: تسجيل ميكروفون خمس ثوانٍ ثم تحويل الملف ليس بديلًا عن بث منخفض التأخير.
- ليس هناك اختبار مماثلة لمنتج ElevenLabs أو تدريب جديد مثبت في هذا المستودع.

## الاختبارات

\`\`\`powershell
python -m pip install -r requirements-dev.txt
python -m pytest -q
\`\`\`

يتضمن الملف \`tests/test_audio_tools.py\` **1000 حالة اختبار فعلية ومختلفة** بمعلمات محددة مسبقًا، تغطي تنويعات القنوات والملفات والتردد والترشيح والبوابة الصوتية، إضافة إلى اختبارات API والقوائم والتصاريح والجهوزية. هذه ليست ألف تجربة استماع أو ألف عملية استدلال GPU حقيقية.

## التدريب من داخل الموقع

تُشغّل الواجهة أوامر Applio الرسمية بالترتيب: preprocess ثم extract ثم train. ابدئي بعد تثبيت Applio وإعداد مجلد خاص يحتوي على 10 تسجيلات WAV أو أكثر، وملف manifest.jsonl يحدد النص، وهوية المتحدث، وconsent=true، والتقسيم إلى train/validation/test.

في PowerShell اضبطي:

    $env:APPLIO_ROOT = 'C:\path\to\Applio'
    $env:APPLIO_PYTHON = 'C:\path\to\Applio\.venv\Scripts\python.exe'
    $env:APPLIO_TRAIN_DATA = 'C:\path\to\consented-dataset'

اختاري اسم نموذج جديدًا وعدد Epochs وحجم Batch وGPU. يتطلب الموقع تأكيد الإذن وتأكيد تشغيل مهمة طويلة. تعرض صفحة حالة الوظائف المرحلة الحالية، ويمكن تنزيل السجل من /api/jobs/{id}/training-log. إذا لم ينتج Applio ملف checkpoint صالحًا، تُعد المهمة فاشلة. لا يعني اجتياز الاختبارات الآلية أن التدريب على البطاقة الرسومية قد جُرّب فعلًا.
