# Mina Voice Studio v0.1.0-alpha

**First public developer-preview release** — open-source, local-first character voice casting and dialogue preparation for animation.

This is a packaging/documentation milestone, **not an audio-quality certification or hosted demo**.

## Included

- Arabic/English desktop-style web UI and local FastAPI service.
- Cartoon Cast scene scripts with characters, voice references, approximate acting/pause directions, timed WAV clips and episode WAV/SRT/ZIP exports.
- Optional adapters to the original Qwen3-TTS VoiceDesign, Base clone and CustomVoice models (English and other upstream supported languages; not Arabic).
- Chatterbox Multilingual V3/Turbo/Nano interfaces, Applio/RVC conversion and training orchestration, Demucs separation, Faster-Whisper transcription, cleanup and quality measurements.
- Optional Qwen Kaggle evaluation notebook and Resemblyzer speaker-similarity reporting.
- CI-tested Python/HTTP flows, PCM16 processing and Chromium UI, plus contributor and issue-reporting documentation.

## What the alpha does NOT include

- Pretrained neural model checkpoints, bundled RVC models or guaranteed voice quality.
- A public GPU demo, auto lip-sync, realtime voice changer, production-grade multitenant authentication or an animation editor.
- Claims of ElevenLabs/Applio superiority or completed GPU quality benchmarks. **Some CI paths use model stubs, not model inference.**

## Setup

1. Get the source from this GitHub tag.
2. Install Python 3.11 or 3.12, then `python -m pip install -r requirements.txt`.
3. Run `python -m uvicorn studio.app:app --host 127.0.0.1 --port 7860`.
4. To synthesize real speech, separately install/configure your preferred model environment using [the Arabic setup guide](https://github.com/ahpa5246-lgtm/mina-voice-studio/blob/main/docs/INSTALL_AR.md).
5. For a GPU experiment, follow [the Kaggle notebook](https://github.com/ahpa5246-lgtm/mina-voice-studio/blob/main/kaggle/cartoon_voices_qwen3.ipynb).
