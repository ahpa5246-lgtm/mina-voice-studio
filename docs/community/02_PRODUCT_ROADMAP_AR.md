# خارطة طريق Mina Voice Studio — صعوبات حقيقية لا عدد أزرار

## ما يمكن قوله الآن
الواجهة محلية، والمستودع يحتوي تكاملات مع Qwen3-TTS وChatterbox وApplio/RVC ومحركات الصوت الأخرى. تم تشغيل Qwen على Kaggle Tesla T4 وعُرضت نتائج صغيرة العينة لست جمل مستنسخة وقياسات ASR، لكن ذلك **لا يثبت جودة كل المحركات أو طبيعية كل المشاعر**. مشروع واسع الميزات لا يعني تلقائيًا منتجًا متكاملًا.

## الأولوية 0 — التثبيت والثقة (الأسابيع 1–3)
1. فحص Windows 10/11 وPython 3.11/3.12 بمستخدم جديد. مخرجات: مسار تثبيت واضح، رسائل فشل، ومخطط مشكلات توافق.
2. زر فحص البيئة يشرح بوضوح سبب عدم تشغيل Qwen أو Chatterbox، وحالة GPU وملفات النماذج.
3. اختبارات Audio smoke بعينات مرخصة وخيار ASR، مع جمع ملفات WAV وبيانات الأجهزة وتسمية تشغيل النموذج الحقيقي.
4. تقليل الالتباس بين المثبَّت والمختبَر؛ حالة واضحة لكل محرك.
5. واجهة عرض لعينة صغيرة للمستخدم الجديد دون تعطيل أو كشف أسرار أو رفع تسجيلات الأشخاص.
**شرط الإنجاز:** مستخدم جديد ينجح في فتح الواجهة؛ وإذا توفر النموذج ينتج مقطع WAV صحيحًا، وإذا لم يتوفر تظهر رسالة صادقة.

## الأولوية 1 — سير إنتاج الكرتون (الأسابيع 4–7)
1. معاينة كل سطر قبل/بعد التغيير وتحويل اختيارات الصوت إلى مشروع محفوظ.
2. نظام أفضل عدة محاولات A/B مع مقارنة صوتية واضحة واحتفاظ باختيار المستخدم.
3. Timeline خفيف للمقاطع الصوتية (إضافة/ترتيب/قص الصمت ثم تصدير)، بشرط اختبار التزامن وعدم كسر نسخ WAV الأصلية.
4. استعادة مهام التوليد بعد إعادة تشغيل الخدمة بلا ازدواجية أو تلف.
5. تحسين وصولية لوحة المفاتيح، الأداء مع المشاهد الطويلة، والواجهة العربية.
**شرط الإنجاز:** إنتاج مشهد أصوات من ثلاث شخصيات، تعديل جملة وحفظ نسخة ثانية، تنزيل ZIP وصيغته قابلة للفتح في محرر الفيديو.

## الأولوية 2 — محركات موثوقة وتعاون (الأسابيع 8–12)
1. تشغيل Chatterbox وApplio على GPU فعلي وتوثيق التراخيص، مع عينة عربية وأخرى إنجليزية.
2. Benchmark مقارن بمدخلات ثابتة، خط أساس، WER/CER وspeaker similarity وRTF وVRAM وحدود التقييم.
3. مراجعة أمان التطبيق قبل تقديم Demo عام متعدد المستخدمين.
4. توثيق واجهات المحركات، إضافة Type checks للبيانات وتحسين تجزئة الاختبارات.
5. مساهمات مترجمة وإصدارات منتظمة ورخص مصادرها واضحة.
**شرط الإنجاز:** مصادر صوت حقيقية وقياسات قابلة للتحقق، وتستطيع مساهمة خارجية المرور في CI دون تدخل غير موثق.

## لا تُدرج كميزات مكتملة
- Lip-sync تلقائي، Timeline إنتاج متكامل، App Windows موقّع، بث حي منخفض التأخير، Cloud GPU مجاني دائم، دعم عربي Qwen الرسمي.
- لا تدّعي تفوقًا على ElevenLabs أو Blender أو Audacity دون اختبار مستقل مطابق.
- لا تُحمّلي المكتبات الضخمة إلى Git؛ استخدمي الأوزان من المصدر/المستضيف وفق التراخيص.

## كيف نقرر تأجيل مهمة؟
- حجم كبير مقابل فائدة ضئيلة، اختلاف ترخيص، عدم القدرة على الاختبار، تكلفة GPU دائمة، مخاطر نسخ صوت غير مصرح بها.
- عند رفض فكرة، اشرحي القرار علنًا وأبقي المساهم محترمًا.
- كل مهمة يجب أن تملك Owner وAcceptance criteria وحجمًا تقريبيًا وفحص CI أو استماع محدد.

## تصنيف جاهزية الميزة
- Proposed: فكرة.
- Implemented: كود موجود.
- Tested: اختبارات محلية موثقة، مع تسمية النماذج إن استُخدمت.
- Validated: اختبار GPU/استماع مستقل على عينة صريحة.
- Production-ready: مرونة تشغيل وأمن وتوثيق ودعم على أجهزة متعددة؛ لا تستعملي هذا الوصف مبكرًا.
