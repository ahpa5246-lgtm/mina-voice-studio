## قائمة العمل اليوم — خطوة بخطوة
- [ ] افتحي GitHub ثم مستودع Mina وتحققي أن حسابك مالك المستودع الأصلي، وأن 2FA وطرق استعادة الحساب تعمل.
- [ ] من الترس بجانب About ضعي الوصف والوسوم المقترحة في الملف 01.
- [ ] من Settings → General → Features فعّلي Discussions وأنشئي قنوات Q&A / Ideas / Showcase / Announcements.
- [ ] من Settings → Rules → Rulesets تحققي من إلزام PR واختبارات CI ومراجعة CODEOWNERS إذا دعمت الخطة هذه القواعد. وجود الملف وحده لا يفرض حماية.
- [ ] اقرئي GOVERNANCE وCONTRIBUTING وSECURITY وأضيفي منشور ترحيب للمجتمع.
- [ ] اختاري 5–8 مهام صغيرة فقط من بنك المهام وافتحي لها Issues مفصلة قابلة للحل.
- [ ] جهزي فيديو حقيقي من 60–90 ثانية يوضح تثبيت البرنامج وتوليد WAV مرخّص وكيف يصدر SRT، بلا لقطات متخيلة.
- [ ] ابدئي بقنوات تتناسب مع جمهور الأنيميشن والصوت وPython. قبل كل منشور راجعي قواعد القناة.
- [ ] اكتبي ملخصًا أسبوعيًا: عدد المستخدمين الذين جرّبوا، المشاكل المحلولة، PRs، النجوم، والأسئلة المتكررة.

## المساهمة الأولى: دورة كاملة
1. المساهم يقرأ CONTRIBUTING ويختار Issue غير محجوزة.
2. يكتب تعليقًا بأنه يريد تنفيذها ويقترح الخطوات.
3. أنتِ تؤكدين معيار القبول وموعد متابعة مناسبًا، وتعينينه إن أمكن.
4. ينشئ Fork وفرعًا، يجري تعديلًا مع اختبارات، ويرسل PR.
5. GitHub Actions تشغّل الاختبارات؛ تقبلين تغييرات آمنة أو تكتبين ملاحظات محددة.
6. بعد الدمج، تشكرينه في سجل الإصدار وتعطينه نسبة المساهمة كاملة.

## متى لا ننشر حملة واسعة؟
حين لا توجد تجربة قابلة للتكرار، أو إذا كانت الصفحة تَعِد بما لم نختبره، أو إذا لم يُستطع الرد على أول مستخدمين، أو إذا كانت لدى المساهمين 0 مهام واضحة. أصلحي ذلك أولًا؛ لا يوجد رقم نجوم مضمون.
