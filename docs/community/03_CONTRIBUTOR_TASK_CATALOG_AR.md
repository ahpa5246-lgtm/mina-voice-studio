# بنك 30 مهمة جاهزة لتوزيعها على مجتمع Mina Voice Studio

**هذه مقترحات Issues وليست وعودًا بميزات موجودة.** قبل فتح كل مهمة تحققي من أن المشكلة لم تُحل في آخر فرع main؛ عدلي المسارات عند تغير البنية.

## كيف تستخدمين البنك
- افتحي Issues → New issue واستخدمي قالب Feature request أو Bug report، أو Issue عادية.
- انسخي عنوان المهمة ووصفها ومعيار القبول أدناه. أضيفي الوسم المذكور فقط إن كان موجودًا.
- البداية الأفضل 5–8 Issues صغيرة، لا تنشري كل المقترحات دفعة واحدة.
- للمبتدئين استخدمي good first issue + help wanted حين تكون البيانات والاختبارات جاهزة. advanced ليست good first issue.
- لمهام GPU اطلبي سجلات نموذج حقيقي دون أي تسجيلات خاصة أو توكن.
- لا تمنحي صلاحية Write أو Admin لمجرد قبول مساهمة؛ Fork → Pull Request يكفي.

**المسار العام:** Issue واضحة → تعليق حجز → موافقة على نطاق الحل → Fork → PR مع اختبارات → CI → مراجعة → دمج → نسبة مساهمة.

## قالب مختصر لتنسخيه في أي Issue
**Problem:** ما العائق الذي يعانيه المستخدم؟  
**Scope:** ما الملفات والواجهة المستهدفة؟  
**Expected behavior:** ما المخرج القابل للفحص؟  
**Non-goals:** ما الذي لا يطلبه هذا الإصلاح؟  
**Acceptance criteria:** 3–5 نقاط قابلة للتحقق.  
**Tests:** أوامر فعلية أو اختبار استماع موثق إن تعلق بالأصوات.  
**Difficulty:** Beginner/Intermediate/Advanced.  
**Maintainer support:** ماذا ستقدمين من أمثلة وبيانات؟  
**Privacy/license:** لا أسرار أو أصوات غير مرخصة.  
**Assignment:** تعليق علني قبل البدء، ثم Fork/PR.
