# Mina Voice Studio — Community Code of Conduct

Everyone may participate regardless of nationality, language, experience or background. We expect respectful discussions, reproducible evidence, and honest credit.

**Expected:** help new contributors, write constructive reviews, include steps to reproduce, respect contributor attribution and third-party licenses, require consent for voice references, and responsibly report security issues.

**Not allowed:** harassment, threats, discrimination, publishing private recordings or secrets, misleading benchmark results, unauthorized voice cloning, automated mass messages, manipulated GitHub Stars/upvotes, and demands that contributors advertise the project to earn acceptance.

These rules apply to project-controlled GitHub Issues, PRs, Discussions and community channels. The lead maintainer may ask for changes, moderate abusive comments or revoke project permissions proportionately. Report security vulnerabilities privately using the process in [SECURITY.md](SECURITY.md); do not place exploit details in public Issues. Respect due process and keep moderator responses factual.
